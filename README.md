### Collect (`/collect`)

- Simulate customer bank consent (sandbox)
- On approve: debit settles → **pool balance increases**
- Same pool the vault withdraws from
- Live: wire Zepto / Monoova / Azupay PayTo keys later

### Vault (`/vault`)
- 6-digit PIN + recovery phrase
- AES-GCM encrypted bank details on device
- Direct BSB / PayID transfer UI (no Stripe, no PayPal)
